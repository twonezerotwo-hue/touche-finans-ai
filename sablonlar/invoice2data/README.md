# invoice2data tedarikci sablonlari

Bu klasordeki `.yml` ve `.yaml` dosyalari otomatik yuklenir. Sistem yalnizca
sablonla eslesen metin tabanli PDF faturalarinda invoice2data sonucunu kullanir;
eslesmeyen veya eksik belgeler mevcut Qwen2.5-VL akisina geri doner.

Yeni bir tedarikci icin genel sablonu kopyalayip `keywords` alanini tedarikciye
ozel VKN/unvan ile daraltin. Once test belgesiyle kontrol etmeden genel regexleri
genisletmeyin.
